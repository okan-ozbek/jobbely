## Maintaining references

Keep one owner for each policy. Update that owner and this route when the implementation or its entry point changes; link to it instead of copying the algorithm or a changelog into startup guides. Verify statements against current code. Plans must distinguish implemented work from proposed/unverified work; dated counts are not permanent guarantees.

For a new decision, add an uppercase concern `.md` filename with status/date, rationale, invariants, implementation/verification links and limits. Update this index, related references and relevant root README links. Preserve historical evidence in its concern document or archive.

Use [QUALITY](QUALITY.md#iteration-and-final-verification) for checks. Reading less unrelated history does not reduce the required checks or authorize skipping a relevant decision.
