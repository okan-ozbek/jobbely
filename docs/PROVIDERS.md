## Enterprise providers

- **Workday:** public CXS read-only POST, empty initial search/no location filters, pagination by actual returned count. Later `total: 0` can be a sentinel, never proof of an empty board. Capped searches partition only by validated single-valued native facets; reconcile exact IDs, overlap, counts and final inventory. Hydrate every detail and retain immutable native ID independently from URL slug. Tenant/site must match canonical and regional application links. Limits remain 2,000 search requests, 10,000 details and two hours. Enumeration/samples alone cannot publish a full import. Malformed NVIDIA entries fail the source rather than disappearing. Slack uses its dedicated board, not a Salesforce text search.
- **iCIMS/Jibe:** page-size 100, explicit total, actual received count; reject duplicates/drift/premature end. Booking.com's native brand filter excludes other Booking Holdings employers; missing membership fails. GitHub's configured posting host alias permits link identity only, not arbitrary fetching. These bindings are part of audit configuration hashes.
- **SmartRecruiters:** only exact configured ServiceNow/Canva public endpoints. Full detail hydration, summary rechecks and native identity/link validation remain required. Preserve every textual advertisement section and authoritative detail metadata; Canva may place the description in `companyDescription`.
- **Workable:** only the configured Hugging Face public widget with full descriptions. Wild-card/general-application exclusions remain explicit. No candidate/application endpoint access.

## Native providers and gates

| Provider                          | Required behavior                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Apple                             | Public structured HTML only, explicit empty `location=`, echoed `locationAsc` order/page, consistent totals/distinct IDs and first-page recheck. Hydrate every detail. Preserve location-suffixed IDs and validated `PIPE-` mappings; parse literal hydration JSON without executing scripts. Internal JSON APIs remain forbidden.                 |
| Netflix/Eightfold                 | Explicit Netflix domain and configured origin. Validate pagination, public state, stable totals and IDs; hydrate every detail and validate same-origin links. Other Eightfold tenants need separate configuration.                                                                                                                                 |
| Amazon                            | Exhaust capped search through exact single-valued native category facets; reject ignored filters, overlap, missing IDs/count drift and changed final facets. Feed supplies full descriptions. Keep `id_icims`, `SF` identities, and validated `HVH` requisition mappings. Application/account URL allowances never authorize fetching those pages. |
| Shopify/Atlassian                 | Exact public routes and complete descriptions; missing details fail publication. See [Shopify](SHOPIFY.md) and [Atlassian](ATLASSIAN.md).                                                                                                                                                                                                          |
| LinkedIn/Meta/Google/ASML/HubSpot | Explicit restricted/unavailable adapters preserve existing data and report failures. Accessible samples, permission flags or an empty fallback feed cannot establish an authorized complete source. See their employer notes and current audit plans.                                                                                              |

Shared pacing/retries/byte limits, provider traversal caps, source renewal and atomic publication remain active. Missing workplace/employment/dates stay unknown. Distinct native posting IDs remain distinct even when titles match. Full descriptions/native labels/original application links are preserved. Complete board traversal does not prove worldwide employer coverage or authorize absence-based closure.
