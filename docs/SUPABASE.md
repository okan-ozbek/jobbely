# Decision: Supabase public Ashby import and talent-form identities

**Status:** Implemented; 51 jobs imported locally with full descriptions, native compensation and matching features. Exact-run technical inventory verified; source candidate and scheduled, with employer scope/access/display reviews pending. Recorded 7 October 2026, Europe/Amsterdam.

## Discovery and rationale

The [official careers page](https://supabase.com/careers) visibly advertises 51 specific openings through [Ashby board supabase](https://jobs.ashbyhq.com/supabase). Every full native posting UUID matches the public version-1 aggregate in both directions. All 51 entries are listed and have complete descriptions; zero generic non-vacancy entries were excluded. One posting displays structured salary/equity compensation with one geographic tier. Native labels, summaries, currency/interval and component text remain intact without calculated pay ranges.

The separate [Talent Community form](https://jobs.ashbyhq.com/supabase/form/talent-community-form) invites updates on future opportunities when no current role fits. It is absent from the job aggregate and does not advertise a specific vacancy. The audit originally interpreted its reserved `form` segment as a posting ID; the parser now keeps Ashby `/board/form/<slug>` URLs as board discovery with no job identity. This preserves reconciliation of real vacancy and application links on the same board. No forms or applications were submitted.

The application owner's continuing onboarding request authorizes local integration/display, and the earlier all-source instruction enables scheduled refreshes. Captured [terms](https://supabase.com/terms) govern hosted Cloud Services and reserve IP rights; [privacy](https://supabase.com/privacy) explicitly excludes applicant processing. The [Acceptable Use Policy](https://supabase.com/aup), version 1 dated 1 June 2026, includes restrictions on unauthorized scraping datasets in its services context. These documents and [Ashby API documentation](https://developers.ashbyhq.com/docs/public-job-posting-api) remain unreviewed evidence, without inferring career republication rights from service or open-source licensing. Employer retrieval/display permission and legal-entity scope remain unverified. No consent, reviewer or approved policy hash is invented; existing explicitly blocked employer plans remain effective.
