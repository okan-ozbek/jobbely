# Decision: ElevenLabs public Ashby import and native inventory

**Status:** Implemented; 137 jobs imported locally with full descriptions, native compensation and matching features. Exact-run technical inventory verified; source candidate and scheduled, with employer scope/access/display reviews pending. Recorded 6 October 2026, Europe/Amsterdam.

## Discovery and rationale

The [official careers page](https://elevenlabs.io/careers) links to its unfiltered [positions inventory](https://elevenlabs.io/careers/positions), displaying 137 openings across five departments. Every visible native link uses a full posting UUID in `/careers/<uuid>/<title-slug>`. The officially linked application script uses Ashby embedding; its public configuration identifies [board elevenlabs](https://jobs.ashbyhq.com/elevenlabs). Scripts were read as text without executing them or opening/submitting application forms.

The public version-1 aggregate supplies 137 listed postings with complete descriptions and original application links. Every official UUID matches a distinct feed UUID; matching counts alone are not the evidence. One posting advertises structured compensation with one tier and salary/equity components; the existing adapter preserves its native summary, currency/interval and component text without computing ranges. Other explicit display flags suppress structured compensation. Generic non-vacancy rules exclude zero entries.

Hosted Ashby metadata advertises the case alias `ElevenLabs`. Both public spellings returned identical posting identities, descriptions and metadata apart from original URL board casing. Reconciliation canonicalizes only this observed alias to `elevenlabs`; unrelated board names and all stored employer/application URLs retain their case.

The application owner's continuing onboarding request authorizes local integration and the earlier all-source instruction enables scheduled refreshes. Employer reviews remain pending. Captured [EEA terms](https://elevenlabs.io/terms-of-use-eu), [non-EEA terms](https://elevenlabs.io/terms-of-use), both dated 31 March 2026, [privacy](https://elevenlabs.io/privacy-policy) and [Ashby API documentation](https://developers.ashbyhq.com/docs/public-job-posting-api) remain evidence rather than fabricated consent or approvals. Public availability and robots permission do not establish description republication rights.

## Runtime invariants

- Stable company/source ID `elevenlabs`, board `elevenlabs`, provider `ashby`, Wave C, shared N/A logo pending vector review. Scheduling follows [SCHEDULING.md](SCHEDULING.md) independently of verification.
- Reuse `https://api.ashbyhq.com/posting-api/job-board/elevenlabs?includeCompensation=true` through the existing adapter and bounded transport. No new ingestion destination, private API, credentials or application submission.
- Preserve complete sanitized HTML/text, native compensation, posting UUIDs, titles, original URLs, department/team, primary/secondary locations, employment/workplace labels and publication dates. Unknown optional values remain unknown.
- Native identity parsing requires HTTPS on exact host `elevenlabs.io`, a complete lowercase UUID and canonical title-slug path. Reject custom ports, credentials, queries/fragments, short prefixes and extra application paths; allow a trailing slash. Visible links supply inventory while embedded URLs establish discovery only; equal titles do not merge different UUIDs.
- Automatic audit uses the exact successful extraction and run ID without a second feed fetch. Technical coverage is distinct from employer scope/access/display approval. Manual traversal/approval flags remain unreviewed. Candidate refreshes cannot advance missing counters or close jobs; explicit blocked plans and removal quarantine remain effective.
- Raw descriptions, policy/script discovery and diagnostics stay in ignored backend data. Compact checked-in evidence records identities, hashes, counts and limitations.

## Implementation and verification

Backfill created 137 matching features; the run retains one successful aggregate snapshot. Database verification compared every active posting with that exact snapshot, including full sanitized descriptions, all native identities and original URLs, titles, department/team, primary/secondary locations, employment/workplace labels, publication dates and the displayed compensation summary/components. Every feature hash matches its posting; the shortest description contains 1,878 characters.

The [compact audit](../backend/config/audit-evidence/elevenlabs.json) matches all 137 official UUIDs in both directions without technical blockers.
